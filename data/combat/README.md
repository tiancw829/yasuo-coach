# 数值计算来源

`16.21.json` 是 `scripts/sync-combat.ts` 从 CommunityDragon 同补丁游戏文件提取的根属性、技能 DataValues、计算节点、消耗与 CD 证据，不是当前任意版本都适用的公式库。每个对象保留原始字段、计算节点及来源 URL。

伤害实现只采用已审阅的亚索／阿狸计算节点，数值数组从技能等级 1 的索引开始，不能把索引 0 或任意 effect 数值当成伤害。等级成长、抗性、小兵攻击次数与意流护盾上限属于程序明确列出的模型规则，尚未逐项游戏内实测。

小兵每击的默认值为游戏文件 Root 基础配置，不含地图生成脚本、时间升级与实际转火模拟，界面允许输入实际面板伤害。不要把它当作游戏任意时间的小兵实战伤害。

增加英雄或支持新补丁前，需重新核对伤害类型、加成、重复命中规则和技能特殊机制，并维护可独立手算的回归测试。
