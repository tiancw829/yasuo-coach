# 批量英雄数值资料

`16.21/` 包含当前官方快照中全部 173 位英雄的同补丁游戏文件提取结果。来源为 CommunityDragon 解析的 Riot 游戏文件，不是拳头官方公开 REST API。文件携带版本、获取日期、原始字段名与来源 URL，可离线使用。

包含基础／成长属性、四个主技能、可用的被动／附加技能、DataValues、计算节点、效果数组、CD、资源消耗和距离字段。主技能包装器可能不含实际伤害数据，变身／武器技能需要看附加条目。DataValues 和效果数组保留原始索引（通常索引 0 是占位），不得擅自当技能 1 级；不同字段的索引规则不同。游戏数据可能含模式专用、未使用和旧说明节点，取到数据不等于核查了机制。

`profiles.json` 明确选定 20 个重点中路英雄的技能伤害分项和条件。计算器只执行白名单中的已确认计算节点与属性类型，其他节点显示为未解析；不自动把百分比、持续伤害和斩杀节点当作直接伤害。分项可能互斥、包含普攻本体或以每球／每秒计量，不允许简单相加为全技能伤害。未计算项目逐英雄列出。尚未逐项进行游戏内验证。

完整双向连招预算目前仍为亚索对阿狸；其他英雄的条件分项和所有英雄的原始数值可随问题发送给 AI。AI 必须区分这两种计算的装备、等级与目标抗性。

批量同步：

```powershell
npm run sync-numerics
# 重新下载同补丁文件，忽略本地下载缓存：
npm run sync-numerics -- --refresh
```

脚本固定使用 16.21（对应官方快照 16.21.1），6 路并行，下载失败最多尝试三次。原始下载缓存放在工作目录 `work/numeric-raw/16.21/`，按补丁隔离；每个输出文件原子写入，manifest 明确成功／缺失状态。增加新补丁必须单独提取和复核，页面的一键官方数据升级不自动批准新的伤害公式。

维护分项规则时，应核对：伤害类型、总／额外 AD、AP／魔抗加成、数组索引、倍率、互斥分支、命中次数、被动触发以及持续时间；修改 revision 并补充独立手算测试。不要为了让所有英雄出现总伤害而给缺失字段填 0。
