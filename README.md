# 御风 · 亚索对线手册

本地中文网页。选择对手，查看一句话策略、三件要记住的事、关键技能 CD、风墙交互、符文、出装与对线阶段。不配置 AI 也能用。

## 在 Windows 上启动

1. 安装 **Node.js 24 LTS**（当前电脑已具备），双击本目录的 **start.bat**。
2. 首次启动会安装依赖，需要联网。之后使用随附数据运行；脚本会检查构建并打开浏览器。
3. 地址是 **http://127.0.0.1:3210**。保留启动窗口，关闭它会停止服务。

不需要 Riot API Key。不要直接双击 index.html，它需要本地服务。重复启动会打开已在运行的页面。

## 已提供的内容

- 随附 16.20.1 与 16.21.1 中文官方快照，可在右上角切换。英雄、技能及推荐装备与符文图片已随附，不需要图片 CDN 在线可用。
- 20 份独立对局攻略：狐狸、劫、永恩、阿卡丽、小鱼人、安妮、拉克丝、辛德拉、发条、维克托、妖姬、塞拉斯、加里奥、刀妹、男刀、冰鸟、蛇女、蚂蚱、小法、阿萝拉。
- 全英雄可搜索：中文名、称号、英文 ID；20 个精修英雄另有常见昵称。未精修英雄显示基础资料与通用建议，不编造专属交互。
- 玩家固定为亚索，中路用途；不连接游戏客户端、不检测敌方技能施放、不运行实时计时。

### 出门装与符文修正（2026-10-19）

常规对拼方案现以**致命节奏**为起点，迅捷步法为难以持续接近时的承压备选，不再默认套用“步法／征服者”两套模板。副系根据具体对局选择复苏之风或骸骨镀层，并写明触发条件。

16.20.1 官方数据包含**多兰之弓**（ID 1086）：400 金币、8 攻击力、15% 攻速、1.5% 全能吸血，不提供生命值。狐狸、劫、永恩、拉克丝等多数可主动换血的对局优先展示多兰弓＋两瓶生命药水（合计 500 金币）。持续承压或需要额外血量时，展示多兰盾或多兰之刃的选择理由；两套出门装分别列出，不能同时购买。出盾不意味着必须放弃致命节奏。

这些搭配是有条件的经验建议，不是实时热门率或最高胜率结论。装备数值能从官方数据核实，具体对局最优搭配仍需真实统计与实战复核。后续版本若缺少多兰弓、符文或改变价格，会显示缺失／预算提示，不能默默照搬旧方案。

## 配置可选 AI

在“AI 设置”里输入：

- **Base URL**：服务商提供的 OpenAI 兼容基础地址，例如 `https://你的服务商/v1`；支持完整 `/chat/completions` 地址。远程地址必须 HTTPS，本机模型可使用 HTTP localhost。
- **模型名称**：服务商提供的准确模型 ID，程序不擅自指定模型。
- **API Key**：该服务商的密钥。

在 AI 教练的主输入框直接输入问题，点击“回答问题”。例如“狐狸 E 各等级基础 CD 是多少？”或“我该什么时候主动换血？”。你的原问题作为本次回答的重点发送，个人情况可在独立折叠栏补充；留空时点击“分析这局”获取整局建议。回答后可连续追问，切换对手或版本会清空旧对话。

也可点击三个预设问题：“符文出装策略”“全技能对拼与小兵影响”“对线策略”，自动填入针对当前对手的完整提问；可修改后点击“回答问题”，选择预设本身不调用接口。对拼预设要求比较 1、2、3、6 级、说明连招与装备等假设，并考虑兵线与小兵仇恨；已支持的亚索对阿狸 16.21.1 对局会附带程序计算结果；其他英雄／补丁缺少已核查公式时明确说明，不编造伤害或胜率百分比。

每次自动加载所选版本的双方英雄基础属性、成长字段、被动、Q/W/E/R 描述、基础 CD 及特殊机制说明，同时保留攻略、风墙、符文和装备资料。可展开“已加载双方属性、被动与 Q / W / E / R”查看发送的英雄资料。模型可以引用已有数值；缺失的伤害、加成、范围和消耗公式不靠猜测补全。成长字段不按简单线性相加，亚索的 mp 不视为法力值，E 的连续施放间隔不视为同目标限制。

点击“保存并测试连接”会使用亚索对狐狸的完整资料，执行与 AI 教练相同的分析、结构与来源校验，不再仅要求模型回复 OK。测试、点击“回答问题”“分析这局”或提交“追问”才会产生请求；选人或展开资料不会自动调用。请求可能消耗 API 额度。相同模型、对局、版本、知识库版本、问题、补充条件和对话历史的结果在服务内存缓存 24 小时（最多 100 条），服务重启后缓存清空；提示词版本也参与缓存，避免复用旧版固定分析。

优先请求 JSON Schema 输出；服务商明确表示不支持时，改用普通 JSON 指令发送一次。返回内容始终由本地 Zod 校验；服务商忽略建议数量限制时，最多接收 20 条格式有效的建议并保留前 5 条，不因返回 7 条建议而直接报错。缺失字段或 JSON 格式错误时，在同一 120 秒时限内最多再调用一次模型修复格式，可能产生额外费用；修复后仍须通过完整结构与来源校验。伪造来源直接拒绝展示，不通过修复补造引用。

单次 AI 操作总等待上限为 120 秒，覆盖连接、接收回答、格式修复及重试；底层连接时限也设为 120 秒，避免默认连接时限提前中断。首次获取 LOL.PS 资料的时间另计。连接重置、短暂 DNS 故障、响应读取中断以及 HTTP 502/503/504 最多自动重试一次；密钥、证书、限流和超时错误不会自动重试。页面显示经过过滤的错误类型，不显示服务商原始响应或密钥。分析资料保留机制、符文和装备信息，去掉不参与分析的本地图片地址等字段。AI 文字与事实卡分开，仍可能存在理解错误。

密钥保存在本机 **.local/settings.json**，不返回前端、不存入 localStorage 或 sessionStorage，也不放入 URL 或日志。该文件是本地明文配置，并非密码保险库。分享项目时必须排除整个 .local 目录；它已加入 .gitignore。更换服务商地址需重新输入密钥，防止把旧密钥误发到新服务。支持清除已保存的密钥。

2026-10-19 已使用本机用户保存的配置实际通过完整连接测试、网页分析和连续追问。自动回归测试继续使用模拟接口，以覆盖断线、格式不兼容和错误响应；通过某次实际验证不代表服务商后续不会发生网络故障，也不代表所有第三方均兼容。

## 数值对拼计算（亚索对阿狸）

AI 教练中增加无需密钥的本地计算器，当前支持 **亚索对阿狸 · Data Dragon 16.21.1 / 游戏文件 16.21**。修改等级、出门装、技能加点、命中次数、E 预叠层、双方静态额外属性和血量后自动重算；计算结果随问题发给模型，由模型解释，不依赖模型心算。

- 输出每项技能／普攻的原始与抗性减伤后伤害、生命和攻速／普攻间隔、法力预算、双方掉血比例，以及 1／2／3／6 级默认连招比较。阿狸 Q 回程按真实伤害，W 后续同目标伤害和 R 每次冲刺命中分别计；亚索 E 用额外 AD／AP 与预叠层计算。亚索 W 伤害为零。
- 出门装属性来自所选官方快照；额外属性输入在出门装外叠加，可填符文碎片或回城后的面板加成。没有自动模拟致命节奏、其他符文触发、点燃、暴击、装备特效、回复和吸血，不能当成包含所有效果的完整对战仿真。
- 可取消魅惑、Q 去回程或其他被躲开／风墙挡住的命中。6 级亚索 R 假设提前攒 Q3 且击飞成功。阿狸法力预算按全部已学技能各施放一轮，未命中仍扣蓝，R 重施放不额外扣蓝。
- 小兵按指定数量持续集火：数量 × floor(暴露秒数 × 配置攻速) × 每击伤害，再按英雄护甲减伤。默认兵数 0；默认每击 11／19.5／36 来自同补丁根配置，未计生成脚本增益、随时间升级和特殊效果，必须按当前实战面板调整。模型不自动预测仇恨、距离或转火。
- 意流盾给出最多吸收一次满盾的掉血范围，约 1 秒持续时间无法覆盖整套连招；没有英雄伤害命中时小兵不会单独触发。未模拟 R 后再次触发的护盾。
- 等级比较复用相同装备／额外属性／兵线，各等级重新按默认加点与连招计算；不复用当前自定义命中开关。它是条件下的伤害和掉血比例比较，不是胜率或单杀概率。

技能公式和成长字段依据 [CommunityDragon 16.21 亚索游戏文件解析](https://raw.communitydragon.org/16.21/game/data/characters/yasuo/yasuo.bin.json)、[阿狸文件解析](https://raw.communitydragon.org/16.21/game/data/characters/ahri/ahri.bin.json)及小兵文件，证据保存在 `data/combat/16.21.json`。这是社区解析游戏文件，不是拳头公开 API；取回并核对了字段与计算节点，尚未逐项游戏内实测。与旧 Meraki 15.9.1 有冲突时，计算器采用同补丁文件，例如亚索 AD 成长 2.5、阿狸 Q 35/60/85/110/135、W 后续倍率 0.4、R 75/125/175。

属性成长显式采用 `g(L)=[0.7025+0.0175×(L−1)]×(L−1)`；正抗性乘 `100/(100+抗性)`，负抗性乘 `2−100/(100−抗性)`。所有规则和假设可在计算器展开核对；尚未逐等级游戏内实测。其他英雄或补丁明确显示不支持，不沿用这组数值。普通“一键升级数据”不会自动提升伤害公式的核查版本。

维护时执行 `npx tsx scripts/sync-combat.ts` 重新取回当前硬编码补丁的来源证据，必须检查差异并更新计算规则和独立手算测试后再发布；不能仅修改版本号宣称新版本已支持。

## 数据、版本与可信范围

### LOL.PS 参考与 AI 整理

AI 教练中默认勾选“参考 LOL.PS 公开统计”。提交问题时读取 [LOL.PS 亚索公开英雄页](https://lol.ps/cn/champ/157?region=0&tier=2&lane=2)的摘要数据，随双方官方数值、技能与本地机制攻略一同发给模型。也可先点“加载参考”预览，不需要模型密钥、不消耗模型额度；取消勾选则本次只附带本地资料。

当前固定为**韩服、翡翠及以上、中路**，不是国服或铂金以上全量数据库。参考包含大众性／高胜率套路的符文、出门装、鞋子、核心装备、三件套及其公开样本字段；对位统计只使用公开摘要实际列出的当前对手，未列出时明确显示“没有当前对手的对位统计”。符文／出装整体统计不能作为该对位的最优方案，整场胜率不等于对线单杀率或某等级对拼胜率。对线技巧由模型结合已核查机制整理，属于策略判断，不能称为网站直接提供的技巧。

页面显示来源链接、补丁、抓取时间、段位、样本及采样时间范围的缺失情况。程序通过来源版本列表匹配补丁：如 Data Dragon `16.21.1` 对应来源 `26.21`；旧补丁仍有公开记录时按版本读取，已下架则显示来源实际版本并提示仅作历史参考，不冒充当前所选版本。源方案的装备／符文会核对本地所选版本，缺失或不可用项不应直接推荐；未加载的属性碎片名称或数值映射不猜测。

仅获取公开英雄页摘要，不访问会员、登录或 `/api` 路径，也不绕过访问限制。返回页面作为静态字面量解析，不执行远程脚本；页面结构、地区／段位参数和数据字段校验失败就回退，不拿缺失数据凑数。缓存保存在 `.local/lolps-cache/`，有效期 6 小时，同版本请求合并，失败后短暂退避；手动“刷新参考”可更新。联网失败优先使用旧缓存并提示，完全无缓存时继续用本地资料。AI 缓存包含来源内容和抓取时间，更新参考后不复用旧结果。

基础数据来自 [Riot Data Dragon](https://developer.riotgames.com/docs/lol#data-dragon)，包含 [版本列表](https://ddragon.leagueoflegends.com/api/versions.json)、中文英雄、装备、符文及素材。该国际服静态版本**不是国服当前版本的自动确认**。

机制参考使用 [Meraki 社区资源](https://cdn.merakianalytics.com/riot/lol/resources/latest/en-US/champions/Yasuo.json)。读取于 2026-10-19，但资源标注版本为 **15.9.1**；已把 21 位英雄的实际来源字段、效果与注释保存在 data/mechanics-evidence.json。当前版本未做游戏内逐项验证，页面明确显示此限制。发条 Q 等来源本身标为待测试的内容保留“待核查”。攻略的 16.20.1 指与官方技能说明和装备目录对应，并不表示所有历史机制已经过当前版本验证。

技能 CD 显示各**技能等级**的基础值，不含技能急速。充能、冷却刷新、多段释放及特殊攻速缩短机制不能仅用这个值理解。亚索 Q 与 E 特别说明；E 的 0.5 等数字是连续施放间隔，不能当作同目标重用间隔。缺失值、模板占位符不猜测。技能档案成长属性保留原始字段；数值对拼计算器使用独立的同补丁游戏文件与显式成长规则，适用范围见下。

对线策略、强势期、难度和本地出装是有条件的经验建议，不展示虚构胜率或样本量。完整国服／韩服铂金以上对局数据库尚未接入；AI 教练的 LOL.PS 公开摘要参考单独标明范围，不批量采集真实比赛。

点击页面右上角 **“一键升级数据”** 即可获取拳头官方最新中文英雄、技能、装备、符文与离线图标，“数据与版本”弹窗中也有相同按钮。页面显示下载阶段与英雄数量，后台运行时可继续查看旧版攻略，刷新页面或重开标签后仍可看到当前任务状态（本地服务需要继续运行）。多个标签页共用同一任务，避免重复下载。

成功后自动切到新版本，旧版本仍可选；若已缓存完整的最新版，检查后直接提示“已是最新”，不会重复批量下载。失败时保留旧快照并提供重试按钮。只有资料、所需素材及格式校验完成后才发布新快照并清理资料与 AI 缓存。**更新基础数据不会复核风墙交互、生成新版对线攻略或接入真实比赛统计**，攻略仍保留原核查版本，不同时显示待复核提示。

## 批量英雄数值与技能分项

- 已随附 16.21.1 的全部 **173 位英雄**游戏文件数值：基础与成长属性、技能 DataValues、计算节点、冷却、消耗和距离。来源为 CommunityDragon 社区解析的同补丁游戏文件，非拳头官方公开 API。
- 「AI 教练 → 全英雄数值资料与技能分项」可离线查看。选择等级、对手装备、额外属性与目标抗性，20 个重点对局可由程序计算条件技能分项。原始资料及计算结果随问题发送给 AI；其他英雄提供原始数值，不套用阿狸公式。
- 分项包含每颗法球、最低斩杀值、互斥强化分支等条件，**不能直接相加为完整连招**。尚未计算的被动、影子、持续伤害、护盾／减伤等逐英雄列出。亚索对阿狸完整连招仍使用独立的原计算器；两处参数独立，回答须区分。
- 原始 DataValues 保留索引 0；主技能规范化 CD／消耗／距离从技能 1 级起展示。未知节点不会执行，版本不同不使用。尚未逐项游戏内实测。
- `npm run sync-numerics` 批量提取固定 16.21 补丁；`npm run sync-numerics -- --refresh` 重新下载。数据、来源与条件规则在 `data/numerics/`；详见该目录说明。官方数据升级按钮不自动核查新补丁公式。
- AI 整体请求及底层连接／响应等待均为 **120 秒**；服务商主动断开或返回错误时仍会提前结束，不能保证远端接口一直保持连接。

- `data/snapshots/`：按版本保存的官方数据；`data/knowledge.json`：攻略；`data/mechanics-evidence.json`：实际取回的旧版机制证据。
- `data/loadouts.json`：逐对局出门装、备选条件与副系符文理由，带独立版本号；该版本号进入 AI 缓存键，修改后不会继续命中旧推荐。
- `scripts/build-knowledge.ts`：20 份攻略的可维护源，修改后执行 `npx tsx scripts/build-knowledge.ts`；核查信息不可随数据更新自动提升。
- `npm run sync-data`：更新官方数据。`scripts/fetch-evidence.mjs` 仅用于重新取回社区来源；执行后需要人工检查差异，不能视为自动复核攻略。
- `public/assets/game/`：离线素材；`dist/`：构建结果；`.local/`：用户私密配置，不可分发。

本地接口：GET `/api/health`、`/api/meta`、`/api/champions?version=...`、`/api/matchup?enemy=Ahri&version=...`、`/api/settings`、`/api/data/update`；PUT `/api/settings`；POST `/api/settings/test`、`/api/advice`、`/api/combat`、`/api/numerics`、`/api/references/lolps`、`/api/data/update`。AI 请求包含 enemy、version、context、question、history、combat（可选完整对拼计算参数）、numeric（可选全英雄分项参数）、useLolps（兼容旧客户端默认 false，网页默认 true）；返回结构化 advice、cached、model、sources 和 reference。参考接口接收 enemy、version、refresh，返回公开统计及其状态，不调用模型。升级 POST 返回 HTTP 202 与任务状态，GET 查询同一任务的 id、state（idle/running/success/error）、message、version 和起止时间；运行中再次 POST 返回已有任务，下载不依赖浏览器长连接。API 全部不缓存到浏览器。
