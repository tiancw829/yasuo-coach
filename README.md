# 御风 · 亚索对线手册

本地中文网页。选择对手，查看一句话策略、三件要记住的事、关键技能 CD、风墙交互、符文、出装与对线阶段。不配置 AI 也能用。

## 在 Windows 上启动

1. 安装 **Node.js 24 LTS**（当前电脑已具备），双击本目录的 **start.bat**。
2. 首次启动会安装依赖，需要联网。之后使用随附数据运行；脚本会检查构建并打开浏览器。
3. 地址是 **http://127.0.0.1:3210**。保留启动窗口，关闭它会停止服务。

不需要 Riot API Key。不要直接双击 index.html，它需要本地服务。重复启动会打开已在运行的页面。

## 已提供的内容

- 16.20.1 中文官方快照：173 位英雄、技能与图标、870 条装备数据、62 个符文。推荐装备与符文图片已随附，不需要图片 CDN 在线可用。
- 20 份独立对局攻略：狐狸、劫、永恩、阿卡丽、小鱼人、安妮、拉克丝、辛德拉、发条、维克托、妖姬、塞拉斯、加里奥、刀妹、男刀、冰鸟、蛇女、蚂蚱、小法、阿萝拉。
- 全英雄可搜索：中文名、称号、英文 ID；20 个精修英雄另有常见昵称。未精修英雄显示基础资料与通用建议，不编造专属交互。
- 玩家固定为亚索，中路用途；不连接游戏客户端、不检测敌方技能施放、不运行实时计时。

### 出门装与符文修正（2026-10-19）

常规对拼方案现以**致命节奏**为起点，迅捷步法为难以持续接近时的承压备选，不再默认套用“步法／征服者”两套模板。副系根据具体对局选择复苏之风或骸骨镀层，并写明触发条件。

16.20.1 官方数据包含**多兰之弓**（ID 1086）：400 金币、8 攻击力、15% 攻速、1.5% 全能吸血，不提供生命值。狐狸、劫、永恩、拉克丝等多数可主动换血的对局优先展示多兰弓＋两瓶生命药水（合计 500 金币）。持续承压或需要额外血量时，展示多兰盾或多兰之刃的选择理由；两套出门装分别列出，不能同时购买。出盾不意味着必须放弃致命节奏。

这些搭配是有条件的经验建议，不是实时热门率或最高胜率结论。装备数值能从官方数据核实，具体对局最优搭配仍需真实统计与实战复核。后续版本若缺少多兰弓、符文或改变价格，会显示缺失／预算提示，不能默默照搬旧方案。

## 配置可选 AI

在“AI 设置”里输入：

- **Base URL**：服务商提供的 OpenAI 兼容基础地址，例如 `https://你的服务商/v1`；支持完整 `/chat/completions` 地址。远程地址必须 HTTPS，本机模型可使用 HTTP localhost。
- **模型名称**：服务商提供的准确模型 ID，程序不擅自指定模型。
- **API Key**：该服务商的密钥。

点击“保存并测试连接”会使用亚索对狐狸的完整资料，执行与 AI 教练相同的分析、结构与来源校验，不再仅要求模型回复 OK。测试、点击“分析这局”或提交“追问”才会产生请求；选人不会自动调用。请求可能消耗 API 额度。相同模型、对局、版本、知识库版本、补充条件和对话历史的结果在服务内存缓存 24 小时（最多 100 条），服务重启后缓存清空。

优先请求 JSON Schema 输出；服务商明确表示不支持时，改用普通 JSON 指令发送一次。返回内容始终由本地 Zod 校验；服务商忽略建议数量限制时，最多接收 20 条格式有效的建议并保留前 5 条，不因返回 7 条建议而直接报错。缺失字段、无效建议与伪造来源仍拒绝展示。

单次操作总等待上限为 120 秒，覆盖连接、接收回答及重试。连接重置、短暂 DNS 故障、响应读取中断以及 HTTP 502/503/504 最多自动重试一次；密钥、证书、限流和超时错误不会自动重试。页面显示经过过滤的错误类型，不显示服务商原始响应或密钥。分析资料保留机制、符文和装备信息，去掉不参与分析的本地图片地址等字段。AI 文字与事实卡分开，仍可能存在理解错误。

密钥保存在本机 **.local/settings.json**，不返回前端、不存入 localStorage 或 sessionStorage，也不放入 URL 或日志。该文件是本地明文配置，并非密码保险库。分享项目时必须排除整个 .local 目录；它已加入 .gitignore。更换服务商地址需重新输入密钥，防止把旧密钥误发到新服务。支持清除已保存的密钥。

2026-10-19 已使用本机用户保存的配置实际通过完整连接测试、网页分析和连续追问。自动回归测试继续使用模拟接口，以覆盖断线、格式不兼容和错误响应；通过某次实际验证不代表服务商后续不会发生网络故障，也不代表所有第三方均兼容。

## 数据、版本与可信范围

基础数据来自 [Riot Data Dragon](https://developer.riotgames.com/docs/lol#data-dragon)，包含 [版本列表](https://ddragon.leagueoflegends.com/api/versions.json)、中文英雄、装备、符文及素材。该国际服静态版本**不是国服当前版本的自动确认**。

机制参考使用 [Meraki 社区资源](https://cdn.merakianalytics.com/riot/lol/resources/latest/en-US/champions/Yasuo.json)。读取于 2026-10-19，但资源标注版本为 **15.9.1**；已把 21 位英雄的实际来源字段、效果与注释保存在 data/mechanics-evidence.json。当前版本未做游戏内逐项验证，页面明确显示此限制。发条 Q 等来源本身标为待测试的内容保留“待核查”。攻略的 16.20.1 指与官方技能说明和装备目录对应，并不表示所有历史机制已经过当前版本验证。

技能 CD 显示各**技能等级**的基础值，不含技能急速。充能、冷却刷新、多段释放及特殊攻速缩短机制不能仅用这个值理解。亚索 Q 与 E 特别说明；E 的 0.5 等数字是连续施放间隔，不能当作同目标重用间隔。缺失值、模板占位符不猜测。成长属性是源数据字段，不实现逐等级伤害模拟。

对线策略、强势期、难度和出装是有条件的经验建议；不展示虚构胜率或样本量。国服/韩服铂金以上统计尚未接入，没有后台悄悄抓取或采集真实比赛。

“数据与版本 → 检查并更新”可下载最新官方快照和所需素材，可能耗时几分钟。只有完整且校验通过的 JSON 才成为可选快照。失败时旧快照继续可用；旧版本保留。更新不会修改攻略原有核查版本，版本不同时会提示待复核。

## 开发与验证

```powershell
npm ci
npm run build
npm start
```

开发模式 `npm run dev`：界面 http://127.0.0.1:5173，本地 API 3210。服务仅监听 127.0.0.1，拒绝跨站访问和非本地主机头；静态目录不包含源码、配置或密钥。

```powershell
npm test
npx playwright install chromium
npm run test:browser
```

测试覆盖攻略数据与本地素材完整性、关键风墙误区、配置密钥保护、异常接口、AI 格式与来源校验、缓存分离、中文搜索、移动布局和切换对手时清空追问。浏览器测试的 AI 为模拟响应，不使用真实密钥。

维护说明：

- `src/`：React 页面与样式；`server/`：Fastify API、攻略组合、AI 适配；`shared/`：类型及校验定义。
- `data/snapshots/`：按版本保存的官方数据；`data/knowledge.json`：攻略；`data/mechanics-evidence.json`：实际取回的旧版机制证据。
- `data/loadouts.json`：逐对局出门装、备选条件与副系符文理由，带独立版本号；该版本号进入 AI 缓存键，修改后不会继续命中旧推荐。
- `scripts/build-knowledge.ts`：20 份攻略的可维护源，修改后执行 `npx tsx scripts/build-knowledge.ts`；核查信息不可随数据更新自动提升。
- `npm run sync-data`：更新官方数据。`scripts/fetch-evidence.mjs` 仅用于重新取回社区来源；执行后需要人工检查差异，不能视为自动复核攻略。
- `public/assets/game/`：离线素材；`dist/`：构建结果；`.local/`：用户私密配置，不可分发。

本地接口：GET `/api/health`、`/api/meta`、`/api/champions?version=...`、`/api/matchup?enemy=Ahri&version=...`、`/api/settings`；PUT `/api/settings`；POST `/api/settings/test`、`/api/advice`、`/api/data/update`。AI 请求包含 enemy、version、context、question、history；返回结构化 advice、cached 和 model。API 全部不缓存到浏览器。
